## What Skyreth is

Skyreth connects to an existing Pterodactyl panel and gives hosts a real client dashboard:

- Create, gift, and manage servers
- Coins, AFK rewards, coupons, renewals
- Store and resource packages
- Stripe, Tebex, and other payment methods
- Discord join rewards
- Admin tools and an API for bots

It does not replace Pterodactyl. It sits on top of it.

Repo: `SkyrethHQ/skyreth`
